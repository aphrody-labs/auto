Garder Auto à jour

Les données de votre entreprise restent sur votre instance Auto. Un téléchargement ne contient aucun accès à votre compte : connectez-vous avec votre adresse personnelle d’équipe.

  • Windows : les mises à jour natives utilisent un installateur dont la signature est contrôlée par l’application. La vérification dépend de la version installée.
  • Android : l’installation d’un APK demande votre accord dans Android. Une mise à jour doit être signée avec la même clé que l’application installée.
  • Paquets autonomes : destinés à l’hébergement de votre instance, ils nécessitent PostgreSQL et la configuration des services. Ils se distinguent des applications connectées à Auto.
Vérifier un téléchargement

Comparez le SHA-256 affiché avec celui du fichier reçu.

Windows PowerShell : Get-FileHash .\nom-du-fichier -Algorithm SHA256

Linux : sha256sum nom-du-fichier

macOS : shasum -a 256 nom-du-fichier
