Suivre vos factures et vos chantiers

Guide pas à pas, écrit pour quelqu'un qui n'est pas informaticien.

Ce que vous avez reçu

Vous avez deux fichiers :

Fichier À quoi il sert Difficulté
Classeur_Factures_Fournisseurs.xlsx Un classeur Excel où vous notez vos factures et vos paiements. Il calcule tout seul : ce qui reste à payer, les retards, le coût de chaque chantier. Facile. Rien à installer.
Workflow_n8n_Factures_Fournisseurs.json Un « robot » qui lit vos factures scannées et les écrit à votre place dans le classeur. Technique. À faire plus tard, avec de l'aide.
Mon conseil : commencez par la Partie 1 (Excel seul). Utilisez-la une ou deux semaines. Quand vous êtes à l'aise, passez à la Partie 2 pour automatiser.

Partie 1 : utiliser le classeur Excel (sans rien installer)

Comment ça marche, en une image

Vous notez la facture
(onglet Journal)➔ Vous notez le paiement
(onglet Paiements)➔ Excel calcule tout
(onglet Suivi)➔ Vous lisez le résultat
(Tableau de bord)
1

Ouvrir le classeur

Double-cliquez sur Classeur_Factures_Fournisseurs.xlsx. Si Excel affiche un bandeau jaune « Mode protégé », cliquez sur Activer la modification.

2

Comprendre les onglets (en bas de l'écran)

Onglet À quoi il sert Dois-je y écrire ?
Légende Mode d'emploi du classeur Non, à lire
Tableau_de_bord Les chiffres importants : à payer, en retard, coût par chantier Non, à lire
Journal La liste de toutes vos factures Oui
Paiements La liste de tout ce que vous avez payé Oui
Suivi Le détail calculé de chaque facture Non, jamais
Fournisseurs La liste de vos fournisseurs Oui (colonnes A à G)
Chantiers La liste de vos chantiers et leur budget Oui (colonnes A à G)
Plan_comptable, Listes Réglages (comptes, délais de paiement) Rarement
Export_compta, Export_banque Fichiers prêts pour votre comptable Non, à copier
Règle simple : les titres de colonnes bleus sont à remplir. Les titres verts se calculent tout seuls : n'y touchez pas.
3

Effacer les exemples

Le classeur contient de fausses factures pour vous montrer comment il marche. Il faut les enlever.

  • Onglet Journal : cliquez sur le numéro de la ligne 2, glissez jusqu'à la ligne 8. Clic droit ➔ Supprimer ➔ Lignes du tableau.
  • Onglet Paiements : même chose pour les lignes 2 à 4.
  • Onglets Fournisseurs et Chantiers : on les remplace à l'étape suivante.
Attention : n'effacez jamais de lignes dans l'onglet Suivi. Il se met à jour tout seul.
4

Écrire vos fournisseurs

Onglet Fournisseurs. Écrivez par-dessus les exemples, ligne par ligne :

Colonne Quoi mettre Exemple
Code Un code court et unique F001
Nom Le nom du fournisseur Matériaux du Sud
SIRET Les 14 chiffres, sans espaces (sur ses factures) 12345678900011
Délai paiement Nombre de jours pour le payer 30
IBAN, Email Facultatif
Compte tiers Demandez à votre comptable (commence par 401) 401001

Les colonnes H à K (vertes) se remplissent seules.

5

Écrire vos chantiers

Onglet Chantiers. Gardez la ligne 2 (A_AFFECTER) : elle sert à ranger les factures sans chantier. À partir de la ligne 3, écrivez vos chantiers :

  • Code chantier : un nom court sans espace, par exemple DUPONT-2026
  • Libellé, Client, Responsable, dates : pour vous repérer
  • Budget HT : l'argent prévu pour ce chantier, hors taxes
6

Ajouter une facture

Onglet Journal. Écrivez la facture sur la première ligne vide, juste sous la dernière. Le minimum à remplir :

Colonne Quoi mettre
Date facture La date écrite sur la facture (ex : 12/10/2026)
Fournisseur (nom lu) Le nom, comme dans votre liste de fournisseurs
N° facture Le numéro de la facture
Code chantier Choisissez dans la petite liste déroulante
Montant HT, TVA, TTC Les trois montants de la facture

Le reste est facultatif. Échéance (si lue) : à remplir seulement si une date limite est écrite sur la facture. Sinon, Excel la calcule avec le délai du fournisseur.

Un litige ? Écrivez la lettre O dans la colonne « Litige (O) ». La facture sera suivie à part.
7

Enregistrer un paiement

Onglet Paiements, première ligne vide :

  • Date paiement : le jour où vous avez payé
  • Clé facture : cliquez dans la case, puis sur la petite flèche, et choisissez la facture dans la liste
  • Montant payé : la somme versée
  • Mode de paiement : choisissez dans la liste (virement, chèque...)

Vous pouvez payer une facture en plusieurs fois : ajoutez une ligne pour chaque versement. À droite, Excel vous dit s'il reste quelque chose à payer.

La « Clé facture » ressemble à F001|F-20481 : le code du fournisseur, puis le numéro de la facture.
8

Lire le tableau de bord

Onglet Tableau_de_bord. Il se met à jour tout seul :

  • Reste à payer : ce que vous devez encore à vos fournisseurs
  • En retard : les factures dont la date limite est passée (en rouge)
  • Budget par chantier : combien chaque chantier a déjà coûté. La mention DÉPASSEMENT apparaît quand le budget est dépassé

Les statuts d'une facture

Statut Ce que ça veut dire
À payer La date limite n'est pas passée, rien n'est payé
Partiellement payée Vous avez versé un acompte, la date limite n'est pas passée
En retard La date limite est passée et il reste de l'argent à payer
Payée Tout est réglé
Litige Vous avez mis la lettre O : désaccord avec le fournisseur
Doublon La même facture est écrite deux fois : supprimez la ligne en trop dans le Journal
Trop payé Vous avez payé plus que le montant : à régulariser

Si quelque chose ne va pas

Problème Cause probable Solution
Le fournisseur affiche « À CRÉER » Il n'est pas dans l'onglet Fournisseurs, ou son nom est écrit autrement L'ajouter dans Fournisseurs, avec exactement le même nom
La facture est rangée dans « A_AFFECTER » Le code chantier est vide ou n'existe pas dans l'onglet Chantiers Choisir un code dans la liste déroulante
La facture n'apparaît pas dans le tableau de bord Le N° facture est vide Remplir le N° facture dans le Journal
« Clé inconnue » dans Paiements La clé a été tapée à la main avec une faute La choisir dans la liste déroulante
Contrôle montants = « ÉCART » HT + TVA n'est pas égal au TTC Vérifier les trois montants dans le Journal
Les cases sont vides ou affichent des symboles Le classeur est ouvert dans un aperçu (mail, Explorateur) L'ouvrir dans Excel et cliquer « Activer la modification »
Avec cette Partie 1, vous avez déjà un suivi complet. Vous gagnez du temps sur les calculs, les relances et le suivi par chantier. La Partie 2 ajoute seulement la lecture automatique des factures scannées.

Partie 2 : automatiser la lecture des factures scannées

L'idée, en une image

Vous scannez
la facture➔ Elle arrive dans
un dossier partagé➔ Le « robot » (n8n)
la lit➔ La ligne apparaît
dans le Journal

Vous n'avez plus à recopier les factures. Vous vérifiez seulement celles que le robot signale comme douteuses.

Cette partie est technique. Elle demande d'installer un logiciel (n8n), de créer des comptes et de régler des accès réseau. Je vous conseille de la faire avec votre informaticien, ou de me demander de vous guider pas à pas, en direct, sur votre ordinateur.

Ce qu'il faut préparer

Élément À quoi il sert Où l'obtenir
n8n installé et en marche C'est le « robot » Votre informaticien, ou moi
Une clé API Anthropic Le « code secret » qui permet de lire les factures avec l'intelligence artificielle (payant, au nombre de factures lues) console.anthropic.com
Un compte Microsoft (OneDrive) Pour que le robot écrive dans le classeur Excel Vous l'avez déjà
Un dossier partagé sur le réseau Là où le scanner dépose les factures Votre informaticien
Une adresse e-mail d'envoi (facultatif) Pour recevoir les alertes et le récapitulatif du matin Votre messagerie

Les grandes étapes

1

Créer trois dossiers dans le partage réseau

Par exemple A_traiter, Traitees et Erreurs. Réglez le scanner pour qu'il dépose les fichiers dans A_traiter.

2

Mettre le classeur dans OneDrive

Copiez Classeur_Factures_Fournisseurs.xlsx dans votre OneDrive.

3

Autoriser deux fonctions dans n8n

Par défaut, n8n bloque deux fonctions utiles ici (surveiller un dossier et déplacer un fichier). Votre informaticien doit ajouter le réglage NODES_EXCLUDE=[] puis redémarrer n8n.

4

Importer le workflow

Dans n8n : menu ... ➔ Import from file, puis choisissez Workflow_n8n_Factures_Fournisseurs.json.

5

Relier vos comptes

Cliquez sur chaque boîte marquée d'un point d'alerte et choisissez votre compte : clé Anthropic, Microsoft Excel, e-mail. Choisissez aussi le classeur dans OneDrive.

6

Indiquer vos dossiers

Dans la boîte Nouveau scan, tapez le chemin du dossier A_traiter. Dans la boîte Paramètres, tapez le dossier qui contient les trois dossiers.

7

Tester avec une seule facture

Déposez une facture dans A_traiter. Une ligne doit apparaître dans l'onglet Journal, et le fichier doit passer dans Traitees (ou Erreurs s'il y a un doute). Si tout va bien, activez le workflow.

Ce qui se passe ensuite, chaque jour

  • Une facture lue sans problème : la ligne apparaît dans le Journal, la colonne « Contrôle OCR » indique OK, le fichier est rangé par chantier et par année.
  • Une facture douteuse (montants incohérents, scan flou...) : la ligne apparaît quand même, avec À VÉRIFIER. Vous la corrigez dans le Journal, puis vous écrivez OK. Le fichier est dans Erreurs.
  • Chaque matin à 8 h, vous recevez un e-mail : factures en retard, à payer cette semaine, à vérifier. Pas d'e-mail s'il n'y a rien à signaler.
Bon à savoir : les factures sont envoyées à un service d'intelligence artificielle (Anthropic) pour être lues. Vérifiez que cela convient à votre entreprise, notamment pour la confidentialité de vos fournisseurs. Chaque facture lue coûte quelques centimes.

Petit lexique

Mot Sens simple
HT / TVA / TTC Hors taxes / la taxe / toutes taxes comprises. HT + TVA = TTC
Échéance La date limite pour payer
SIRET Le numéro d'identité d'une entreprise (14 chiffres)
Doublon La même facture saisie deux fois
OCR Un programme qui « lit » le texte d'un document scanné
n8n (se dit « n huit n ») Un logiciel qui enchaîne des actions automatiquement, comme un robot
Workflow La liste des actions que le robot fait, dans l'ordre
Clé API Un mot de passe qui permet à un logiciel d'utiliser un service
Credential Dans n8n, l'endroit où l'on range un mot de passe ou une clé
Chantier A_AFFECTER Le « tiroir » où vont les factures dont le chantier n'est pas connu
